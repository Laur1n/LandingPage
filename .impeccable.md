# Design Context — Reference Deployment (Francesca Simone)

> **Template note:** This file documents the design context for the **Francesca Simone reference
> deployment** shipped as demo content in this repository. When adapting the template for another
> client, run `impeccable teach` and replace this file — do not reuse another artist's brand tokens.

Established via `impeccable teach` before any UI implementation (Constitution Principle IV).
Source material: the former live site (https://jazz-isses.de/Francesca/) and direct answers from
the project owner.

## Users

- **Concertgoers / fans**: German-speaking, likely skew adult (30s-60s+), appreciate jazz, chanson,
  and Italian song traditions. Browsing to decide whether to attend a concert — often on mobile,
  often close to an event date.
- **Venue bookers / journalists / presenters**: professional context, need to quickly assess her
  artistic identity, current projects, and how to make contact — often on a desktop during work
  hours. Credibility and clarity matter more to them than atmosphere alone.
- **Prospective voice students**: want to know what she teaches, where, and how to reach her.

Job to be done, in one line: _decide to attend, decide to book, or decide to enroll_ — and in every
case, come away with a clear, memorable sense of who she is as an artist.

## Brand Personality

Three concrete words (not "modern"/"elegant"): **sun-warmed, unhurried, intimate.**

Directly from her own words (the current site's copy, not invented): "italienische Leichtigkeit"
(Italian lightness/ease), "Jazz- und Pop-Sensibilität", "ausdrucksstarke Bühnenpräsenz", "Konzerte,
die berühren" (concerts that touch people), "Eine Stimme zwischen Jazz und mediterraner Poesie",
"Nähe zum Text" (closeness to the lyric/text). Her own quote: _"Musik darf erinnern, verführen,
trösten — und manchmal einfach nach einem Abend in Italien klingen."_ ("Music may remind, seduce,
console — and sometimes simply sound like an evening in Italy.")

This is warmth with restraint — not loud, not corporate, not a nightclub. Think early-evening
light, not midday glare or midnight neon.

## Aesthetic Direction

- **Theme**: Light, warm, editorial. Cream/paper tones, never stark white — reads well for press
  and bookers in daylight, while the warmth carries the "evening in Italy" feeling without going
  dark/moody.
- **Anti-reference (explicit)**: NOT a generic musician/band template — no centered hero photo
  with a rounded-corner frame, no stock "Book Now" button, no identical icon-topped card grid for
  "services". If it could be a Squarespace musician template, it's wrong.
- **Type heritage**: Giambattista Bodoni — the actual Italian type designer who worked in Parma —
  gives a legitimate, non-costume-Italian reference point for a high-contrast display serif,
  rather than reaching for a faux-Italian script font.
- **Color**: No existing brand colors to preserve; free to choose based on the above. Palette
  built around a sun-warmed terracotta accent and a deep ink-teal ("evening sky") secondary,
  on warm cream neutrals — not the AI-cliché cyan/purple gradient palette.
- **Accessibility**: WCAG 2.1 AA baseline (already required by FR-022); no additional bar beyond
  that was requested.

## Design Tokens (source of truth for implementation)

### Typography

- **Display / headings**: "Bodoni Moda" (Google Fonts) — high-contrast didone serif with genuine
  Italian type heritage. Used for the site name, section headings, and the pull-quote. Not on the
  banned reflex list (Fraunces, Playfair Display, Cormorant, etc.) and not a genre cliché.
- **Body / UI**: "Hanken Grotesk" (Google Fonts) — warm humanist grotesque, calm counterpoint to
  the dramatic display face, strong screen legibility for longer biography/project text.
- Modular type scale, fluid via `clamp()` for headings; 5-step scale, ≥1.25 ratio between steps.
- Body copy max-width ~70ch.

### Color (OKLCH — reduce chroma as lightness approaches white/black; never pure #000/#fff)

| Token                      | Value                  | Use                                                                |
| -------------------------- | ---------------------- | ------------------------------------------------------------------ |
| `--color-surface`          | `oklch(97% 0.012 60)`  | Page background (warm cream, not white)                            |
| `--color-surface-raised`   | `oklch(93% 0.016 55)`  | Section/card backgrounds                                           |
| `--color-ink`              | `oklch(22% 0.02 50)`   | Primary text (warm near-black)                                     |
| `--color-ink-muted`        | `oklch(45% 0.02 50)`   | Secondary/muted text                                               |
| `--color-accent`           | `oklch(58% 0.14 40)`   | Terracotta — links, active nav, key accents (used sparingly, ~10%) |
| `--color-accent-strong`    | `oklch(48% 0.15 38)`   | Hover/pressed state of accent                                      |
| `--color-evening`          | `oklch(30% 0.06 230)`  | Deep ink-teal — secondary accent, footer background                |
| `--color-evening-contrast` | `oklch(95% 0.015 220)` | Text on `--color-evening`                                          |

60% surface / 30% ink & muted text / 10% terracotta accent, per the 60-30-10 weight principle.

### Spacing

4pt scale with semantic names: `--space-xs: 4px`, `--space-sm: 8px`, `--space-md: 16px`,
`--space-lg: 24px`, `--space-xl: 32px`, `--space-2xl: 48px`, `--space-3xl: 64px`, `--space-4xl: 96px`.

### Motion

Amended for feature 002 (clarified "Showcase" scroll storytelling) — the binding scene inventory
and rules live in `specs/002-content-migration-redesign/contracts/motion.md`. Summary:

- Scroll-driven choreography via GSAP ScrollTrigger: staged hero entrance, scrubbed portrait
  parallax, pinned pull-quote scene (desktop only), CD-cover strip drift, per-block reveals.
- Non-negotiables unchanged from the original context: exponential ease-out for entrances,
  transform/opacity only (never layout properties), no bounce/elastic easing, native scrolling
  (no hijacking), `prefers-reduced-motion` disables pinning/parallax/scrubbing entirely.
- Content-first: every animated element is fully visible in server HTML; initial offsets are
  applied only by JS at init. No JS ⇒ complete page, zero CLS from animation.
- Color note (002 clarification "warm editorial minimal"): terracotta stays the single accent;
  `--color-evening` is reserved for large quiet surfaces (footer, program-page pitch band) and
  must not be used as a second accent color.

### Explicit bans carried over from the `impeccable` skill

No side-stripe borders (`border-left`/`border-right` accents on cards), no gradient text, no
glassmorphism, no identical icon-topped card grids, no generic rounded-shadow cards, no modals
unless there is truly no better alternative.

## Notes for implementers

These tokens should be defined once as CSS custom properties in `src/styles/tokens.css` (or
equivalent) and consumed by `BaseLayout.astro` and every section component, rather than
re-declared ad hoc, so the site stays visually cohesive as more sections are built.
